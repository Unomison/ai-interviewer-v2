# Milestone 2 — LLM gateway: completion report

Date: 2026-11-03 · Spec: *AI Interviewer: Build Specification (Zero to One)*, Rev 2, §8

## What is done

- **Gateway** (`apps/api/src/llm/gateway.js`): one module exposing
  `generate({ task, prompt, schema, stream })`, `embed(texts)` and
  `budgetAllows(task)`. Factory `createGateway({ env, configOverrides,
  fetchImpl, logger })` plus a default singleton. Structured JSON logs for
  every attempt/failover/cache hit/budget block; prompts are never logged
  (spec §10).
- **Adapters** (`apps/api/src/llm/adapters/`): `gemini.js` (REST
  `generateContent`, `x-goog-api-key` header, `responseMimeType` +
  `responseSchema` structured output, `embedContent` embeddings),
  `groq.js` + `openrouter.js` (shared OpenAI-compatible layer in
  `openai-compat.js`: chat completions, `response_format: json_object`, SSE
  streaming), `ollama.js` (dev-only, gated by `OLLAMA_ENABLED=true`, never in
  the visitor's path). No vendor SDKs — plain `fetch`.
- **`config.yaml`** (spec-mandated yaml; new `yaml` dep): per-task provider
  chains for `parse`, `ats_rubric`, `planner`, `interviewer`,
  `approach_judge`, `report`, `embed` — Gemini → Groq → OpenRouter, with Groq
  first for the high-volume `interviewer` task and a fast-model override
  (`llama-3.1-8b-instant`) for it. All limits, budgets, timeouts and the
  cache size are config, not code.
- **Failover**: 429 → brief back-off, next provider; 503/timeout/network →
  provider unhealthy for `cooldownMs` (60s) and routed around; 401/403 →
  skip without cool-down; 400/validation failures → thrown immediately, never
  failed over (fail loudly per spec).
- **Quota awareness**: per provider+model daily request/token counters vs
  config limits (Gemini ~1,400 req/day, Groq 900 req/day — verified
  2026-11-03); global `budgetAllows()` (300 calls / 2M tokens per day)
  checked before every call; exhaustion throws the friendly
  "interviewer is resting" message (spec §2).
- **Caching**: successful responses cached by SHA-256 of
  task+prompt+JSON-schema in an in-memory LRU (200 entries). In-memory in M2;
  Mongo-backed cache is an M8 item (ADR 003).
- **Structured output**: JSON-schema constrained requests where supported
  (converted from Zod via `zod-to-json-schema`), ALWAYS Zod-validated;
  one retry with the validation error appended, then a loud
  `ValidationError`.
- **Mock fallback**: zero keys configured → deterministic mocks generated by
  walking the Zod schema (`mock.js`, seeded PRNG, respects min/max/email/url
  checks, nested objects, enums) and `safeParse`d before return; mock
  embeddings are deterministic 768-dim unit vectors. The pipeline runs
  end-to-end with no keys (owner decision, ADR 002).
- **Streaming**: `generate({ stream: true })` returns
  `{ provider, model, textStream }` — basic passthrough (real SSE parsing for
  the OpenAI-compat adapters; single-chunk for Gemini/Ollama). Full SSE
  wiring for the interviewer is an M8 item; no gold-plating now.
- **Tests** (`tests/llm.gateway.test.js`, `node --test`, NO real keys — one
  fake HTTP server mimics both wire formats via `*_BASE_URL` overrides):
  12/12 passing — same schema-validated call per adapter (gemini/groq/
  openrouter), 429→failover, 503→cool-down respected on the immediate second
  call, validation failure→exactly one retry then loud `ValidationError`,
  cache hit→provider not called again, zero-key deterministic mock (incl.
  nested schema + embed), budget exhaustion→resting message,
  chain-exhausted→`NoProviderAvailableError`.
- **Docs**: this report, `docs/decisions/003-llm-gateway-design.md` (9 design
  decisions), README gateway section, `.env.example` (all four key vars,
  commented, "host dashboard, never in git"). Root `package.json` now declares
  `"type": "module"` like every workspace (silences the ESM warning).
- **Verified model facts (2026-11-03)**: Gemini `gemini-2.0-flash` free
  (~1,500 req/day); embeddings MUST use `gemini-embedding-001` —
  `text-embedding-004` returns 404 since June 2026; Groq OpenAI-compat
  endpoint with `llama-3.3-70b-versatile` (1,000 req/day, 100K tok/day) and
  `llama-3.1-8b-instant` (14,400 req/day, 500K tok/day); OpenRouter free
  models use the `:free` suffix.

## New concepts explained (spec rule 1)

- **LLM gateway**: one module all features call instead of talking to AI
  providers directly — it picks the provider, retries, validates and caches.
- **Failover**: when one provider rate-limits or goes down, the gateway
  automatically tries the next one in the chain.
- **Content-hash cache**: identical requests (same task + prompt + schema)
  are answered from memory instead of spending quota again.
- **Mock mode**: with no API keys, the gateway invents deterministic,
  schema-valid answers so the whole pipeline still runs — useful for demos
  and CI.
