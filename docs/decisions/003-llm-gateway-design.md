# ADR 003 — LLM gateway design (Milestone 2)

Date: 2026-11-03
Status: Accepted

## Context

Spec Section 8 requires one Node module exposing `generate({task, prompt,
schema, stream})` and `embed(texts)`, with per-task provider chains, failover,
quota awareness, caching, and Zod-validated structured output — all on free
tiers, behind swappable adapters, with zero keys still yielding a working
pipeline (owner decision, ADR 002).

## Decisions

### 1. `config.yaml` is the single tuning surface

Model names, chains, limits, budgets, timeouts and the cache size all live in
`apps/api/src/llm/config.yaml` (the spec mandates yaml). Code reads it once at
gateway creation; `createGateway({ configOverrides })` deep-merges overrides
for tests. Rationale: free-tier model names and quotas change often (verified
again 2026-11-03 — see below); the owner should retune without touching code.

### 2. One adapter interface, one shared OpenAI-compat layer

Every adapter exports `{ name, keyEnv, supportsStreaming, isConfigured(env),
generate(), generateStream(), embed() }`. Groq and OpenRouter share
`adapters/openai-compat.js` (chat completions + SSE parsing) since both speak
the OpenAI wire format. Gemini uses its own REST format (`x-goog-api-key`
header, `responseMimeType`/`responseSchema` for structured output). No vendor
SDKs — plain `fetch` keeps the dependency footprint at `yaml` +
`zod-to-json-schema`.

### 3. Failover taxonomy (not just "retry")

- **429** → brief back-off (`resilience.backoffMs`), try the next provider.
  Rate limits are per-key/per-model; the next provider is usually fine.
- **503 / timeout / network error** → provider marked unhealthy for
  `resilience.cooldownMs` (60s) and routed around.
- **401/403** → skip the provider without cool-down (a bad key won't heal in
  60s, but the next provider has its own key).
- **400/422 and Zod validation failure** → thrown immediately, no failover.
  A malformed request or a contract violation is our bug; spraying it across
  providers burns quota and hides the problem (spec: "fail loudly").

### 4. Deterministic mock-from-Zod-schema for zero-key mode

When no provider is configured at all, the gateway serves mocks generated by
walking the caller's Zod schema (`mock.js`: seeded PRNG, respects
min/max/email/url/uuid checks, enums, nested objects, arrays). The mock is
`safeParse`d before return — a mock that fails its own schema is a loud
internal error, never silent bad data. This keeps the whole pipeline
runnable with zero keys (local dev, CI, and the deployed demo's worst case).

### 5. Per-task model override (Groq fast model for interviewer turns)

Spec Section 8 wants the strongest model for judgement-heavy tasks and cheap
volume for chatty ones. `config.yaml` supports `taskModels` per provider:
Groq uses `llama-3.3-70b-versatile` generally but `llama-3.1-8b-instant` for
the `interviewer` task (14,400 req/day vs 1,000 req/day on the free tier —
verified 2026-11-03).

### 6. In-memory quota/cooldown/cache state in M2; Mongo later

Request/token counters, the unhealthy map and the LRU cache are in-memory.
A Render free instance sleeps and restarts, resetting them — acceptable for
M2 (fail-safe direction: counters reset *up*, never blocking legitimate use).
M8 (interview engine) moves them to MongoDB so state survives restarts.

### 7. Budget is checked before the cache

`budgetAllows()` runs before the cache lookup. A cached answer costs no
quota, but the daily budget is also the "how many interviews per day" lever;
checking first keeps one simple, predictable rule.

### 8. Verified model/endpoint facts (2026-11-03)

- Gemini: `gemini-2.0-flash` (free ~1,500 req/day, 15 rpm); embeddings via
  **`gemini-embedding-001`** — `text-embedding-004` returns HTTP 404 since its
  June 2026 retirement.
- Groq: OpenAI-compatible at `https://api.groq.com/openai/v1`; free
  `llama-3.3-70b-versatile` (1,000 req/day, 100K tokens/day),
  `llama-3.1-8b-instant` (14,400 req/day, 500K tokens/day).
- OpenRouter: OpenAI-compatible at `https://openrouter.ai/api/v1`; free
  models carry the `:free` suffix; key optional (chain skips when absent).
- Ollama: dev-only, gated by `OLLAMA_ENABLED=true`, never in the chain
  otherwise.

### 9. Streaming is a basic passthrough in M2

`generate({ stream: true })` returns `{ provider, model, textStream }` (async
generator). Real SSE parsing is implemented for the OpenAI-compat adapters;
Gemini/Ollama yield single chunks. Structured validation over streams and the
interviewer's SSE wiring arrive in M8 — no gold-plating now.

## Consequences

- M3+ call `gateway.generate({ task, prompt, schema })` and get validated
  data or a clear error; they never touch provider SDKs.
- `docs/free-tier-facts.md` should gain the 2026-11-03 quota figures.
- M8 must add the Mongo-backed usage/cache store and the SSE interviewer
  path; M7's research module reuses `generate()` for extraction.
